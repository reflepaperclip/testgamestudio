## 왜 이 시스템이 필요한가
플레이어는 적의 시야와 소리를 피하며 이동해야 한다. 은신 시스템은 탐지 위험을 직관적으로 피드백하고, 플레이어가 전략적으로 경로를 계획할 수 있게 한다.

## 시스템 개요
은신 시스템은 세 가지 주요 요소로 구성된다:
1. **시야 감지**: 적의 원뿔형 시야각 내에서 플레이어가 보이는지 판단
2. **청각 감지**: 플레이어의 움직임 소음이 일정 거리 내에서 적에게 전달됨
3. **의심 및 경보 상태**: 적이 플레이어를 감지했을 때의 반응 단계 (의심 → 경보 → 전투)

## 세부 설계

### 1. 시야 감지
- 적마다 시야 범위와 각도가 정의됨 (예: 전방 120도, 거리 10m)
- 시야 내에 장애물(벽, 상자 등)이 있으면 시야 차단
- 플레이어가 시야에 완전히 들어갔을 때 "발견" 상태 트리거
- 부분적으로 가려진 경우(반쯤 가려진 상태)도 탐지 가능하나 확률 감소 (게임 밸런스용 파라미터)

### 2. 청각 감지
- 플레이어의 행동에 따라 소음 값 발생 (걷기: 낮음, 달리기: 높음, 총 발사: 매우 높음)
- 소음은 거리에 따라 감쇠 (예: 1/r^2)
- 적마다 청각 민감도와 청각 범위 정의 (예: 15m 이내에서 특정 소음 이상이면 반응)
- 소음이 감지되면 적은 해당 방향으로 머리를 돌림 (의심 상태)

### 3. 의심 및 경보 상태
- **의심 상태**: 적이 무언가를 느꼈지만 확실하지 않음. 몇 초 동안 경계하거나 해당 지역을 탐색함.
- **경보 상태**: 적이 플레이어를 확실하게 감지함. 경보음을 내고 근처 적에게 알림을 보냄.
- **전투 상태**: 경보 후 일정 시간 지나도 플레이어가 보이지 않으면 적이 수색을 시작함. 플레이어가 전투 상태에서 은신에 성공하면 적이 다시 의심 상태로 돌아갈 수 있음.
- 은신 성공 조건: 적의 시야와 청각 범위 밖에서 일정 시간(예: 3초) 머무르면 의심 상태가 해제됨.

### 4. 은신 도구 (선택적)
- **소음 제약기**: 일시적으로 자신의 소음 값을 감소시키는 아이템 (쿨타임 있음)
- **광학 위장**: 짧은 시간 동안 시야 감지 범위를 감소시키는 스킬

## Godot 구현 연결
- **노드/씬 구성**:
  - `Enemy.tscn`: 루트 `CharacterBody2D`, 자식 `VisionArea2D` (Area2D), `HearingArea2D` (Area2D), `StateMachine` (혹은 Script)
  - `Player.tscn`: 루트 `CharacterBody2D`, 자식 `NoiseEmitter` (해당 액션 시 노이즈 값 발출)
- **데이터**:
  - `EnemyConfig.tres`: 필드 `vision_angle` (deg), `vision_distance` (m), `hearing_sensitivity` (float), `hearing_range` (m), `suspicions_time` (sec), `alert_time` (sec)
- **신호(Signal)**:
  - `enemy_spotted` (player_node): 적이 플레이어를 발견했을 때 발신
  - `enemy_suspicion` (direction): 적이 무언가를 감지했을 때 발신 (방향 벡터)
  - `alert_triggered` (enemy_node): 경보 상태가 될 때 인근 적에게 알림
- **입력**:
  - InputMap 액션: `move_left`, `move_right`, `move_up`, `move_down`, `sprint`, `fire` (총 발사 시 노이즈 발생)
- **오토로드(싱글톤)**:
  - `StealthManager`: 전역에서 현재 경보 수준, 활성 경보 여부 등을 관리 (옵션)
- **저장 대상**:
  - 현재 은신 상태 (발견됨 여부)는 세이브에 저장하지 않음 (버티컬 슬라이스에서는 세이브 없음). 진행 상황은 정보 획득 개수로 저장.

## 표현 요소
- **행동·AI**:
  - 트리거: 플레이어가 시야/청각 범위 내에 들어감
  - 반응: 상태 전이 (순찰 → 의심 → 경보 → 전투), 적이 플레이어를 향하여 회전 및 이동
- **모션**:
  - 적 순찰 애니메이션: Idle (1.5s), Walk (무한 루프, 속도 1.5 m/s)
  - 의심 상태 애니메이션: AlertLook (2초 정도 주위를 살핌)
- **소리**:
  - 발걸음 소리: 걷기 (부드러운 발소리), 달리기 (빠른 발소리)
  - 발견 소리: 적에게서 경보 음 (비프음 또는 외침)
  - 총소리: loud noise
- **화면 반응**:
  - 플레이어가 발견되면 화면 가장자리에 빨간 테두리 깜빡임 (또는 UI 아이콘 표시)
  - 의심 상태에는 노란 아이콘 표시
- **에셋 요청**:
  - 적 스프라이프 (다양한 방향)
  - 시야 영역 시각화 (디버그용 반투명 원뿔)
  - 소음 파동 시각화 (선택적)
  - UI 아이콘: 눈 (발견), 귀 (의심), 경보 (벨이런 표현)
