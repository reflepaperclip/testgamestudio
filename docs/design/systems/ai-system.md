## 왜 이 시스템이 필요한가
적의 행동이 플레이어의 은신 전략에 직접적인 영향을 미친다. 적의 감지, 상태 전이, 협동 행동을 구체화해야 은신 시스템이 의미 있게 동작한다.

## 시스템 개요
적 AI는 다음과 같은 상태 머신을 갖는다:
- **순찰 (Patrol)**: 정해진 경로를 따라 움직이며 플레이어를 주시하지 않음
- **의심 (Suspicion)**: 무언가를 감지했으나 확실하지 않음. 해당 방향으로 시선을 돌리고 잠시 정지하거나 수색함
- **경보 (Alert)**: 플레이어를 확실히 감지함. 경보음을 내고 근처 알림을 전달하며 추적 행동을 시작함
- **전투 (Combat)**: 직접 플레이어를 향해 사격하거나 접근하여 전투를 시도함
- **탐색 (Search)**: 경보 후 플레이어가 사라진 경우, 마지막 알려진 위치 주변을 수색함
- **복귀 (Return)**: 수색 후 플레이어를 찾지 못하면 원래 순찰 경로로 복귀함

각 상태는 전환 조건과 행동이 명확히 정의됨.

## 세부 설계

### 1. 상태 전환 조건
| 현재 상태 | 다음 상태 | 조건 |
|---|---|---|
| 순찰 | 의심 | 청각 감지 또는 시야 가장자리에서의 미미한 움직임 감지 |
| 순찰 | 경보 | 시야 내에 플레이어가 완전히 들어옴 |
| 의심 | 순찰 | 의심 시작 후 일정 시간(3초) 동안 추가 감지 없음 |
| 의심 | 경보 | 의심 중 시야 내에 플레이어가 들어옴 |
| 경보 | 전투 | 경보 상태에서 플레이어가 사거리 내에 있고 적이 무기를 갖고 있는 경우 |
| 경보 | 탐색 | 경보 상태에서 플레이어가 시야에서 사라지고 일정 시간(2초) 경과 |
| 탐색 | 순찰 | 탐색 경로를 완료하고 플레이어를 찾지 못함 |
| 탐색 | 복귀 | 탐색 중 우연히 플레이어를 재발견 시 경보로 전환 |
| 전투 | 순찰 | 전투 중 플레이어가 특정 거리 이상 벗어나고 적이 손실을 감지 (간단한 후퇴 로직) |
| 전투 | 탐색 | 플레이어가 시야에서 사라지고 일정 시간 후 수색으로 전환 |

### 2. 상태별 행동
- **순찰**:
  - 속도: 1.5 m/s
  - 경로: 웨이포인트 사이를 왕복 또는 루프
  - 시야 주기적 스캔 (게임 로직에서는 지속적으로 검사)
- **의심**:
  - 속도: 0 (정지) 또는 느린 회전
  - 행동: 플레이어가 마지막으로 감지된 방향을 바라봄, 가끔 head tilt
  - 타이머: 의심 시작 시간 기록, 타임아웃 시 순찰로 복귀
- **경보**:
  - 속도: 0 (경보음 발출 후) 또는 추적 시 3.0 m/s
  - 행동: 경보음 재생, 근처 적에게 알림 신호 전송 (예: 신호 범위 내의 모든 적에게 `alert_received` 신호)
  - 추적: 마지막으로 본 플레이어 위치로 이동 (직선 또는 내비게이션 사용)
- **전투**:
  - 속도: 2.0 m/s (플레이어를 향해 이동하면서 사격)
  - 행동: 일정 간격으로 총알 발사 (노이즈 발생), 플레이어를 향해 회전
- **탐색**:
  - 속도: 2.0 m/s
  - 행동: 마지막 알려진 위치 주변을 원형 또는 웨이포인트 기반으로 수색
- **복귀**:
  - 속도: 1.5 m/s
  - 행동: 원래 순찰 경로의 가장 가까운 웨이포인트로 이동하여 순찰 재개

### 3. 협동 행동
- 경보가 발생하면 알림 신호는 일정 반경(예: 20m) 내의 모든 적에게 전달됨.
- 알림을 받은 적은 즉시 경보 상태로 전환하고, 마지막으로 알려진 플레이어 위치로 이동함 (혹은 알림을 보낸 적의 위치로 이동하여 협동 수색).

### 4. 시야 및 청각 재사용
- 적의 시야와 청각 은 은신 시스템과 동일한 파라미터를 공유함 (중복 정의하지 않음). 적 설정에서 시야 각도, 거리, 청각 범위 등을 정의하고, 은신 시스템에서 이를 읽어 감지 로직에 사용함.

## Godot 구현 연결
- **노드/씬 구성**:
  - `Enemy.tscn`: 루트 `CharacterBody2D`
    - 자식: `StateMachine` (또는 `AnimationTree` + 스크립트), `VisionArea2D`, `HearingArea2D`, `AudioSource2D` (경보음), `WeaponNode` (총알 발사 지점)
- **데이터**:
  - `EnemyConfig.tres`: 
    - `vision_angle`, `vision_distance`
    - `hearing_sensitivity`, `hearing_range`
    - `patrol_speed`, `alert_speed`, `combat_speed`
    - `suspicion_timeout`, `alert_timeout`, `search_timeout`
    - `weapon_damage`, `weapon_range`, `weapon_cooldown`
    - `alert_signal_range` (알림 전달 거리)
    - `patrol_path` (Path2D 참조 또는 웨이포인트 배열)
- **신호(Signal)**:
  - `state_changed` (previous_state, new_state): 상태 전이 시 로그 혹은 디버그용
  - `alert_signal_sent` (position): 경보 상태에서 알림 신호를 보냄
  - `alert_signal_received` (sender_position): 알림을 수신한 적에게 전달
  - `weapon_fired` (position, direction): 총알 발사 시 (총알 인스턴스 생성용)
  - `enemy_spotted` (player_node): 은신 시스템과의 연동을 위해 (중복 방지 위해 어느 쪽에서만 발생시키도록 조율)
- **입력**:
  - 적 AI는 입력 없음 (자율行为). 단, 디버그용으로 특정 키를 눌러 상태 강제 변경 가능 (개발용).
- **오토로드(싱글톤)**:
  - `CombatManager` (옵션): 총알 풀 관리, hit detection 중앙화
- **저장 대상**:
  - 적의 현재 상태와 위치 등은 세이브에 저장하지 않음 (버티컬 슬라이스). 적의 수치는 난이도 조정을 위해 별도 설정 파일에 둘 수 있음.

## 표현 요소
- **행동·AI**:
  - 트리거: 시야/청각 감지, 알림 수신
  - 반응: 상태 전이, 이동 경로 변경, 애니메이션 변경
- **모션**:
  - 순찰 애니메이션: Walk loop
  - 의심 애니메이션: Idle + 가끔 헤드 틸트 (또는 `SuspicionLook`)
  - 경보 애니메이션: AlertPose (머리를 뒤로 젖히고 외치는 동작) 또는 단순히 빠른 회전
  - 전투 애니메이션: Shoot (총발사 애니메이션) + 이동
  - 탐색 애니메이션: Walk (수색 중)
- **소리**:
  - 발걸음 소리: 순찰/탐색/복귀 시 걷기 소리, 전투 시 빠르게 움직이는 발소리
  - 경보음: 적마다 고유한 경보 외침 또는 비프음
  - 총소리: 무기 발사 시 큰 소리
  - sospe치 소리: 의심 상태에서의 간단한 끅 소리 (옵션)
- **화면 반응**:
  - 적이 경보 상태일 때 머리 위에 느낌표 아이콘 표시
  - 의문 상태일 때 물음표 아이콘 표시
  - 전투 상태일 때 화살표 아이콘 (플레이어 방향) 표시
- **에셋 요청**:
  - 적 스프라이프 시트 (8방향 또는 4방향)
  - 경보음, 총소리, 발걸음 소리 (다양한 표면)
  - UI 아이콘: 느낌표, 물음표, 방향 화살표
  - 총알 스프라이프 및 이펙트
