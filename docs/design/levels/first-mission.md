## 1. 이 구역이 왜 필요한가
첫 미션은 플레이어에게 게임의 핵심 메커니즘을 모두 가르치고 검증해야 함. 은신, 적 피하기, 정보 수집, 탈출이라는 전체 루프를 경험하게 함으로써 게임의 재미를 전달함. 이 구역은 튜토리얼 역할과 동시에 버티컬스라이스의 목표를 달성하는 임무이어야 함.

## 2. 전제 조건
- 진입 전 상태: 플레이어는 기본 이동 및 은신 조작법을 아는 상태 (간단한 프롬프트나 초기 구역에서 학습 assumed)
- 이 구역의 해금 조건: 게임 시작 시 자동 해금
- 규모(예상 플레이 시간): 12-15분 (버티컬스라이스 목표)

## 3. 공간 구조
도면(이미지). 축척과 범례 필수. 구획 목록: ID, 이름, 크기(m), 역할.

```
[간단한 텍스트 도면으로 표현 - 실제 개발 시 이미지로 대체]
진입점 [A] → 순찰로 [B] → 은신 연습 구역 [C] → 첫 정보 포인트 [D] 
                               ↓
                        경비 초소 [E] → 메인 건출 [F] → 정보 객체 [G]
                               ↓
                        탈출로 [H] → 추적 구역 [I] → 탈출점 [J]
```

구획 목록:
| ID | 이름 | 크기(m) | 역할 |
|---|---|---|---|
| A | 진입점 | 5x5 | 게임 시작 지점, 기본 조작 안내 |
| B | 순찰로 | 20x8 | 기본 순찰 적 배치, 시야 학습 구역 |
| C | 은신 연습 구역 | 15x10 | 벽 뒤에 숨기 연습, 은신도 시스템 체험 |
| D | 첫 정보 포인트 | 5x5 | 간단한 상호작용 객체, 기본 정보 수집 학습 |
| E | 경비 초소 | 10x10 | 약간 강화된 적 배치, 협력적 적 행동 학습 |
| F | 메인 건출 | 25x20 | 주요 건물, 여러 층 및 방 구조 |
| G | 정보 객체 | 3x3 | 목표 데이터 저장소, 상호작용 필요 |
| H | 탈출로 | 15x8 | 정보 수집 후 탈출 경로, 적 재배치 구역 |
| I | 추적 구역 | 30x12 | 정보 수집 후 추적 적 증가 구역 |
| J | 탈출점 | 5x5 | 미션 완료 지점, 성공 피드백 제공 |

축척: 1칸 = 1m
범례: █ = 벽, · = 바닥 공간, P = 플레이어 시작, E = 적, I = 정보 객체, X = 탈출점

## 4. 동선과 흐름
핵심 경로, 선택 경로, 지름길/잠금 해제. Mermaid 플로우 또는 구획 연결 표.

핵심 경로 (추천 루트):
A → B → C → D → E → F → G → H → I → J

선택 경로 (지름길 및 루트):
- B → C 대신 B → F 직접 건물 진입 (더 높은 위험, 더 빠른 경로)
- F 내부에서 여러 경로 존재 (좌측 통로, 중앙 계단, 우측 환기 duct)
- H → I 대신 H → J 직접 탈출 (더 높은 위험, 추적 적 없음)

| 구획 | 연결 | 조건 | 비고 |
|---|---|---|---|
| A | B | 항상 open | 게임 시작 연결 |
| B | C | 항상 open | 은신 연습 권장 경로 |
| B | F | 항상 open | 지름길 옵션 (높은 위험) |
| C | D | 항상 open | 은신 후 전진 |
| D | E | 항상 open | 정보 수집 후 전진 |
| E | F | 항상 open | 건출 진입 |
| F | G | 정보 객체 접근 시 | 목표 달성 |
| G | H | 정보 획득 후 open | 탈출 경로 개방 |
| H | I | 항상 open | 기본 탈출 경로 |
| H | J | 정보 획득 후 open | 지름길 탈출 경로 (추적 있음) |
| I | J | 추적 생존 시 open | 일반 탈출 경로 |

## 5. 페이싱
시간 순 긴장/휴식 곡선. 전투/탐색/퍼즐 비율.

| 구간 | 예상 시간 | 활동 | 긴장도(1~5) |
|---|---|---|---|
| A-B (진입 → 순찰로) | 0-2분 | 기본 이동 및 조작 학습, 순찰 관찰 | 2 |
| B-C (순찰로 → 은신 연습) | 2-4분 | 은신도 시스템 체험, 벽 뒤로 숨기 연습 | 3 |
| C-D (은신 연습 → 첫 정보) | 4-6분 | 간단한 정보 수집 학습 | 2 |
| D-E (첫 정보 → 경비 초소) | 6-8분 | 순찰 패턴 학습, 타이밍 잡기 연습 | 3 |
| E-F (경비 초소 → 메인 건출) | 8-10분 | 건출 진입, 내부 탐색 시작 | 3 |
| F-G (건출 내부 → 정보 객체) | 10-12분 | 건물 탐색, 적 피하기, 목표 접근 | 4 |
| G-H (정보 획득 → 탈출로) | 12-13분 | 정보 획득 성공, 탈출 준비 | 3 |
| H-I-J (탈출로 → 추적 구역 → 탈출점) | 13-15분 | 추적 적 피하기, 최종 탈출 | 5 |
| J (탈출점) | 15분 | 미션 완료 피드백 | 1 (해방감) |

전투/탐색/퍼즐 비율: 0%/70%/30% (은신 게임이므로 전투 없음, 탐색 70%, 퍼즐적 요소 30%)

## 7. Godot 구현 연결
- **씬 파일 경로**: `res://levels/first_mission/first_mission.tscn`
- **루트 노드**: `Node3D` (3D 레벨 기준)
- **구획 단위 서브씬**: 각 구역을 별도 서브씬으로 분할 (예: `zone_a.tscn`, `zone_b.tscn` 등)
- **타일/그리드 방식**: `MeshInstance3D`로 커스텀 모델 사용 (지형의 복잡함으로 인해 TileMap보다는 명시적 모델 사용 권장)
- **충돌 레이어 이름**: 
  - `layer_1`: 세계 기본 충돌 (벽, 바닥)
  - `layer_2`: 플레이어 전용 상호작용 객체
  - `layer_3`: 적 전용 충돌 (플레이어는 지나갈 수 있음)
  - `layer_4`: 총알 등 투사체용 (해당 시)
- **내비게이션 영역**: `NavigationRegion3D` 노드로 각 구역별 내비게이션 메쉬 베이크
- **스폰 포인트 노드 이름**: 
  - `PlayerStart`: 진입점 A 위치
  - `EnemySpawn_B`: 순찰로 B의 적 스폰 포인트들 (2개)
  - `EnemySpawn_E`: 경비 초소 E의 적 스폰 포인트들 (3개)
  - `EnemySpawn_F`: 메인 건출 F의 적 스폰 포인트들 (4개)
  - `EnemySpawn_H`: 탈출로 H의 적 스폰 포인트들 (2개)
  - `EnemySpawn_I`: 추적 구역 I의 적 스폰 포인트들 (4개)
- **로드/스트리밍 단위**: 구역별로 분리하여 원거리 구역은 로드 지연 (단순 구조이므로 전체 로드도 가능)

## 9. 플레이 테스트 항목
길을 잃는 지점 예측, 난이도 스파이크, 막힘 방지(소프트락) 점검.

- **길을 잃는 지점 예측**: 
  - 구역 B에서 C로 가지 않고 벽을 따라 계속 갈 수 있음 → 구역 C로 가는 명시적 표시 필요
  - 건물 F 내부에서 여러 경로가 있어 방향 감각 상실 가능 → 랜드마크 및 조명로 유도
  - 탈출 후 구역 I에서 목표가 보이지 않을 때 → 미니맵에 탈출점 표시 필요
- **난이도 스파이크 예측**: 
  - 구역 E에서 F로 진입 시 적 밀도 증가 → 은신 연습 구역 C에서 충분히 연습한 후 접근
  - 구역 I의 추적 난이도 급증 → 구역 H에서 충분히 정보를 얻어 추적 경로 계획 시간 확보
- **막힘 방지(소프트락) 점검**: 
  - 정보 객체 G 접근 경로가 모두 막힐 가능성 → 최소 2개 이상의 접근 경로 확보
  - 탈출점 J로 가는 길이 모두 적에게 막힐 가능성 → 시간 기반 문 개방 메커니즘 또는 대체 경로 제공
  - 플레이어가 구석에 완전히 틀어박혀 나올 수 없을 때 → 자가 탈출 메커니즘 (일정 시간 후 도움 요청 옵션)
