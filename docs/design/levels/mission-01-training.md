## 1. 이 구역이 왜 필요한가
이 훈련 시설은 플레이어에게 게임의 핵심 메커니즘을 가르치는 튜토리얼 미션이다. 여기서 플레이어는 은신도 시스템, 기본 이동 및 은신 행동, 탐지 시스템과의 상호작용을 배운다. 전체 진행에서의 위치: 게임의 첫 미션으로, 이후 미션들의 기초가 된다.

## 2. 전제 조건
- 진입 전 상태: 플레이어는 기본 이동 능력과 은신도 게이지 UI를 볼 수 있음
- 이 구역의 해금 조건: 게임 시작 시 자동 해금
- 규모: 예상 플레이 시간 10-15분 (버티컬 슬라이스 목표)

## 3. 공간 구조
도면은 별도의 이미지 파일에 있지만, 여기서는 텍스트로 구획을 나열한다. 축척: 1칸 = 2m.

| 구획 ID | 이름 | 크기(m) | 역할 |
|---|---|---|---|
| A01 | 시작점 | 4x4 | 플레이어 스폰 지점, 기본 이동 튜토리얼 프롬프트 표시 |
| A02 | 은신도 게이지 설명 영역 | 6x4 | 은신도 게이지 작동 원리 설명 패널 |
| A03 | 간단한 장애물 코스 | 10x8 | 낮게 세워진 벽과 상자로 이루어진 코스, 이동 및 점프 연습 |
| B01 | 탐지 시스템 소개 영역 | 8x6 | 정찰 로봇이 일정 경로를 순찰하며, 시야 콘 표시 |
| B02 | 침묵 제거 연습 영역 | 6x6 | 무력화 가능한 적 인형이 서 있음, 접근 시 은신도 증가 설명 |
| B03 | 목표물 격리 구역 | 4x4 | 훈련용 목표물 (데이터 단말기) |
| C01 | 탈출 지점 | 4x4 | 미션 완료 지점, 목표물 상호작용 후 활성화 |

## 4. 동선과 흐름
핵심 경로: A01 → A02 → A03 → B01 → B02 → B03 → C01
선택 경로: A03에서 상자를 이용해 높은 길을 따라 B01 측면을 접근 가능 (더 낮은 은신도 증가)
지름길/잠금 해제: 없음 (튜토리얼에서는 모든 영역을 순차적으로 지나야 함)

| 구획 | 연결 | 조건 | 비고 |
|---|---|---|---|
| A01 → A02 | 항상 열림 | - | 프롬프트: "WASD로 이동하세요" |
| A02 → A03 | 항상 열림 | - | 프롬프트: "Shift로 달릴 때 은신도가 빠르게 증가합니다" |
| A03 → B01 | 항상 열림 | - | 프롬프트: "붉은 원은 적의 시야 범위입니다. 안에 들어오면 탐지됩니다" |
| B01 → B02 | 항상 열림 | - | 프롬프트: "적 뒤에서 접근하면 은신도 증가가 적습니다" |
| B02 → B03 | 항상 열림 | - | 프롬프트: "E키로 상호작용하여 적을 무력화시킵니다" |
| B03 → C01 | 목표물 상호작용 후 | 데이터 단말기 해킹 완료 | 프롬프트: "목표물을 달성하고 탈출 지점으로 이동하세요" |

## 5. 페이싱
| 구간 | 예상 시간 | 활동 | 긴장도(1~5) |
|---|---|---|---|
| 시작점 → 은신도 게이지 설명 | 1분 | 이동 및 UI 관찰 | 1 (튜토리얼) |
| 은신도 게이지 설명 → 장애물 코스 | 2분 | 이동 연습, 은신도 게이지 변화 관찰 | 2 |

## 7. Godot 구현 연결
- 씬 파일 경로: `res://levels/mission_01_training.tscn`
- 루트 노드: Node3D
- 구획 단위 서브씬: 각 구획별로 StaticBody3D 또는 Area3D로 충돌 영역 정의
- 타일/그리드 방식: 3D GridMap 사용 (간단한 블록 형태 수준)
- 충돌 레이어 이름: 
  - `world_statics`: 벽, 상자 등 이동 불가 오브젝트
  - `player`: 플레이어 충돌 몸체
  - `enemy`: 적 충돌 몸체
- 내비게이션 영역: `NavMesh` 내비게이션_mesh 인스턴스 (적 AI용)
- 스폰 포인트 노드 이름: 
  - `PlayerSpawn`: A01 중앙
  - `EnemyPatrolStart`: B01 순찰 로봇 시작점
  - `EnemySpawn_B02`: B02 적 인형 위치
- 로드/스트리밍 단위: 단일 씬으로 전체 미션 로드 (작은 규모)

## 8. 표현 요소
- 조명 톤: 훈련 시설이라 밝은 형광등 조명, 그림자는 선명하게 만들어 시야 범위 표시를 보완
- 환경음:遠く에서 에어컨 소리, 발소리 echoes
- 시그니처 랜드마크: 시작점 위의 큰 간판에 "TRAINING FACILITY" 표시
- 에셋 요청 목록:
  - 3D 모델: 상자, 낮은 벽, 순찰 로봇, 적 인형, 데이터 단말기, 탈출 지점 표시등
  - 텍스처: 금속 벽, 콘크리트 바닥, 유리 패널 (설명 패널용)
  - 사운드 효과: 발소리 (걸음, 달리기), 로봇 이동 소리, 적 neutralization 소리, 데이터 단말기 해킹 소리
  - UI 요소: 은신도 게이지 (이미 진행된 시스템에서 재사용), 설명 패널 텍스트

## 9. 플레이 테스트 항목
- 길을 잃는 지점 예측: 
  - A03에서 B01로 가는 길에 플레이어가 순찰 로봇의 시야를 misunderstand 할 수 있음 → 시야 콘을 더明显하게 표시
  - B02에서 뒤로 접근하는 것이 어려운 경우 → avvicinarsi da dietro 프롬프트를 반복 표시
- 난이도 스파이크: 없음 (튜토리얼이므로 지속적으로 낮은 난이도 목표)
- 막힘 방지(소프트락) 점검: 
  - 데이터 단말기 해킹이 불가능한 경우를 대비해 시간 제한 후 자동 완료 옵션 고려
  - 플레이어가 구획 사이에 낄 수 있는 충돌 영역이 없는지 확인
