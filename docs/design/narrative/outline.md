## 1. 이 이야기가 왜 필요한가
이 이야기는 플레이어에게 목적과 맥락을 제공하여 단순한 메커니즘 반복이 아닌 의미 있는 행동을 하게 한다. 긴장감 조절 필러와 연결되며, 플레이어가 "왜 잠입해야 하는가"를 이해함으로써 행동에 무게를 실어 준다. 주인공의 임무 성공은 세계의 안보에 직접적인 영향을 미친다는 서사적 stakes를 제공한다.

## 2. 전제 조건
- 세계관 한 단락: 근future (2028년), 사기업이 불법으로 개발한 생물무기를 비밀 시설에서 생산하고 있음. 플레이어는 초국가 특수부대의 일원으로서施設에 잠입하여 증거를 확보하고 시설을 무력화해야 함.
- 시대·장소: 2028년, 북유럽의 깊은 산 속에 숨겨진 비밀 연구 시설
- 톤(키워드 3개): 긴장감, 전문성, 고립감
- 금지 요소: 과도한 폭력 묘사, 초자연적 요소, 정치적 메시지의 직접적 전달

## 7. 선택과 분기
선택 지점, 영향 범위, 합류 지점. 분기 수를 통제하는 규칙.
- 선택 지점: 미션 3에서 두 가지 경로 중 선택 (조용한 경로 vs 빠른 경로)
  - 조용한 경로: 더 긴 경로지만 적 encounters 적음, 은신도 관리가 쉬움
  - 빠른 경로: 짧은 경로지만 적 탐지 위험 높음, 빠르게 진행 가능
- 영향 범위: 선택한 경로에 따라 미션 완료 시간과 은신도 최대 값이 달라지며, 이는 다음 미션의 시작 은신도에 작은 영향 (누적되지 않음)
- 합류 지점: 두 경로는 목표물 앞에서 다시 합류
- 분기 수를 통제하는 규칙: 하나의 미션당 최대 2가지 주요 경로, 분기의 영향은 해당 미션 내에만 한정하고 전반적인 스토리는 변경하지 않음

## 8. 대사와 텍스트 규칙
- 톤: 전문적이고 간결한 군대식 커뮤니케이션, 감정에 휩쓸리지 않는 어조
- 길이 제한: 라디오 메시지당 1문장 이내, 설명 패널당 2문장 이내
- 표시 방식: 
  - 라디오 통신은 화면 상단에 자막 형태로 표시 (말풍선 사용 안 함)
  - 환경 스토리텔링은 아이템 설명이나 벽에 쓰여진 텍스트로 전달
  - 아이템 설명은 최대 100자 이내
- 로컬라이즈 키 규칙: 
  - 라디오: `radio.<미션번호>.<상황>.<순서>`
  - 환경 텍스트: `env.<구역명>.<아이템ID>`
  - 아이템 설명: `item.<아이템ID>.description`

## 9. 표현 요소와 에셋 요청
- 컷신/연출: 게임 시작 시 간단한 브리핑 컷신 (2D 이미지 + 텍스트), 미션 간 전이는 로딩 화면에서 팁 표시
- 보이스: 라디오 통신은 텍스트만 사용 (보이스 제작 비용 절감), 아이템 발견 시 간단한 효과음
- 환경 스토리텔링 소품: 
  - 실험실 폐기물통에 특이한 생물학적 표시
  - 과학자의 개인 사진이 꽂힌 책상
  - 비상 상황에 대비한 매뉴얼이 보이는 선반
  - 시설 지도가 붙어 있는 벽 (일부 구역은 가려져 있음)
