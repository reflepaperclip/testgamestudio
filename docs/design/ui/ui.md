## 목표
플레이어가 은신 상태와 목표를 직관적으로 파악하고, 조작에 대한 피드백을 즉시 받을 수 있도록 한다. 복잡한 메뉴 없이 게임에 몰입할 수 있는 최소한의 UI를 제공한다.

## UI 요소 개요
1. **은신 게이지** (선택적): 현재 탐지 위험 수준을 보여주는 원형 또는 바 게이지
2. **미니맵** (선택적): 적의 마지막 알려진 위치와 자신의 위치 표시
3. **목표 표시**: 문서함 및 탈출 지점에 세계 내 아이콘 (빌보드)로 표시
4. **상호작용 프롬프트**: 상호작용 가능한 오브젝트 근처에 표시되는 키 아이콘 (예: "E")
5. **경보 표시**: 경보 발생 시 화면 가장자리에 빨간 테두리 또는 아이콘 플래시
6. **의심 표시**: 적이 의심 상태일 때 머리 위에 물음표 아이콘
7. **탐지 표시**: 적이 플레이어를 발견했을 때 머리 위에 느낌표 아이콘 및 화면 효과
8. **엘립스 텍스트** (옵션): 미션 목표 간단 텍스트 표시 (좌상단)
9. **멈춤 메뉴**: ESC 키로 pausing, 설정, 재시작, 종료 옵션

## 세부 설계

### 1. 은신 게이지
- **목표**: 플레이어가 현재 얼마나 노출되어 있는지를 직관적으로 보여줌
- **표시 방식**: 화면 좌하단에 원형 게이지 (또는 바). 게이지가 채워질수록 탐지 위험 증가.
- **값 기준**:
  - 0%: 완전 은신 (시야 및 청각 범위 밖)
  - 30%: 약간 노출 (청각 범위 근접 또는 시야 가장자리)
  - 60%: 위험 (시야 가장자리 또는 청각 범위 내 저소음)
  - 85%: 위기 (시야 범위 내에 일부분 노출)
  - 100%: 탐지됨 (시야 내 완전히 노출 또는 청각 감지 후 의심 상태 진행)
- **컬러**: 녹색 → 노란색 → 빨간색 그라데이션
- **업데이트 주기**: 매 프레임 (또는 0.1초 간격)으로 적의 감지 상태를 기반으로 계산

### 2. 미니맵 (선택적 구현)
- **목표**: 지형과 적의 마지막 알려진 위치를 보여줌으로써 경로 계획을 돕음
- **표시 방식**: 화면 우상단에 원형 또는 사각형 미니맵. 회전하지 않음 (북쪽이 위).
- **표시 요소**:
  - 플레이어: 녹색 점
  - 적 (마지막 알려진 위치): красный 점 (의심 상태는 노란색, 경보 상태는 빨간색 점 pulsating)
  - 목표물: 파란색 아이콘 (문서함), 초록색 아이콘 (탈출 지점)
  - 지형 윤곽: 간단한 실선 (건물 외곽 등)
- **범위**: 레벨 전체를 보여주거나, 플레이어 주변 특정 반경 (예: 30m) 확대
- **토글 옵션**: 설정에서 미니맵 표시/비표시 선택 가능 (하드코어 모드에서는 비표시)

### 3. 목표 표시 (월드 스페이스 아이콘)
- **목표**: 세계 내에서 목표물의 위치를 바로 보고 가도록 함
- **표시 방식**: 빌보드 형태로 항상 카메라를 향하는 스프라이�
  - 문서함: 종이 더미 아이콘
  - 탈출 지점: 문이 열린 모양 아이콘
- **거리 기반 페이드**: 멀리서는 작게, 가까이에서는 크게 (최대 크기 제한)
- **벽 통과 방지**: 레이캐스트를 통해 벽 뒤에 있으면 반투명 또는 아예 표시하지 않음 (옵션)

### 4. 상호작용 프롬프트
- **목표**: 상호작용 가능한 오브젝트 근처에 어떤 키를 눌러야 하는지 보여줌
- **표시 방식**: 오브젝트 머리 위에 작은 아이콘 + 텍스트 (예: "[E] 획득")
- **표시 조건**: 플레이어가 상호작용 범위(예: 2m) 내에 들어갔을 때
- **애니메이션**: 프롬프트가 약간 pulsating하여 Aufmerksamkeit를 끈다
- **키 바인딩**: InputMap에서 정의된 액션에 따라 동적으로 표시 (예: 상호작용 액션은 기본 "E")

### 5. 경보 표시
- **목표**: 적이 경보 상태가 되었을 때 플레이어에게 즉각적으로 알림
- **표시 방식**:
  - 화면 가장자리에 빨간색 테두리가 짧은 시간(0.5초) 동안 flashes
  - 혹은 화면 중앙에 경보 텍스트 "ALERT!"가 크게 나타났다 사라짐
  - 적 머리 위에 빨간색 느낌표 아이콘이 지속적으로 표시 (경보 상태 동안)
- **트리거**: 적의 상태가 경보로 변경될 때

### 6. 의심 표시
- **목표**: 적이 무언가를 감지했으나 확실하지 않은 상태를 보여줌
- **표시 방식**: 적 머리 위에 노란색 물음표 아이콘
- **지속 시간**: 의심 상태가 유지되는 동안
- **추가 효과**: 적이 해당 방향을 바라보는 애니메이션과 함께 아이콘이 ligeramente 흔들림

### 7. 탐지 표시
- **목표**: 적이 플레이어를 발견했을 때 eindeut하게 알림
- **표시 방식**:
  - 적 머리 위에 빨간색 느낌표 아이콘
  - 화면 중앙에 큰 빨간색 텍스트 "SPOTTED!" 표시 (1초 후 페이드 out)
  - 화면 효과: 짧은 진동 또는 화면 가벼운 흔들림 (카메라 shake)
- **트리거**: 적의 상태가 경보에서 전투로 전환되거나, 은신 시스템에서 탐지 값이 임계점을 넘을 때

### 8. 미션 목표 텍스트 (옵션)
- **목표**: 현재 주요 목표를 텍스트로 지속적으로 알려줌
- **표시 방식**: 화면 좌상단에 작은 반투명 박스에 텍스트 (예: "문서함을 찾아라")
- **갱신 조건**: 목표 달성 시 텍스트 변경 (예: "문서 획득! 탈출구로 이동하라")
- **폰트**: 읽기 쉬운 sans-serif, 크기 작게

### 9. 멈춤 메뉴
- **목표**: 게임을 일시정지하고 설정을 변경하거나 재시작할 수 있게 함
- **표시 방식**: 화면 중앙에 반투명 어두운 배경 위에 메뉴 리스트
  - 항목: 계속하기, 설정, 재시작, 메인 메뉴로 이동, 종료
- **입력**: 위/아래로 이동, 엔터 또는 space로 선택
- **설정 하위 메뉴**: 음량 조절, 미니맵 토글, 키 바인딩 보기, 난이도 선택 (옵션)

## Godot 구현 연결
- **노드/씬 구성**:
  - `UI.tscn`: 루트 `CanvasLayer`
    - 자식: `StealthGauge` (TextureProgressBar 또는 맞춤 Controll), `Minimap` (TextureRect 또는 Viewport), `WorldIcons` (노드들, 빌보드 처리 via Shader 또는 스크립트), `InteractionPrompt` (Label + TextureRect), `AlertFlash` (ColorRect 또는 AnimationPlayer), `EnemyIndicator` (적마다 빌보드 아이콘), `MissionText` (Label), `PauseMenu` (Panel에 버튼들)
- **데이터**:
  - `UIConfig.tres`: 색상, 크기, 타이밍 값 등
  - 또는 별도의 리소스 없이 하드코딩 (버티컬 슬라이스에서는 단순화)
- **신호(Signal)**:
  - `stealth_value_changed` (value): 은신 게이지 값 업데이트 시
  - `enemy_state_changed` (enemy_node, new_state): 적 상태 변경 시 UI 업데이트
  - `interaction_prompt_show` (prompt_text, position): 상호작용 프롬프트 표시 요청
  - `interaction_prompt_hide`: 프롬프트 숨기 요청
  - `alert_triggered`: 경보 발생 시 플래시 애니메이션 재생
  - `mission_update` (new_text): 미션 목표 텍스트 변경 요청
  - `pause_menu_requested`: 일시정지 메뉴 호출 요청
- **입력**:
  - InputMap 액션:
    - `ui_cancel`: 일시정지 메뉴 토글 (또는 전용 pause 액션)
    - `interact`: 상호작용 프롬프트가 표시될 때 해당 액션 입력 시 상호작용 실행
    - `ui_up`, `ui_down`, `ui_left`, `ui_right`: 메뉴 탐색용 (멈춤 메뉴에서)
    - `ui_select`: 메뉴 항목 선택
- **오토로드(싱글톤)**:
  - `UIManager` (옵션): UI 요소들의 생성 및 업데이트를 중앙 관리 (복잡한 UI가 아닐 경우 각 씬에서 직접 관리 가능)
- **저장 대상**:
  - UI 설정 (미니맵 표시 여부, 음량 등)는 세이브에 저장할 수 있음 (옵션). 버티컬 슬라이스에서는 세이브 없음.

## 표현 요소
- **행동·AI**: UI는 게임 상태에 반응함 (적 상태, 은신 값 등)
- **모션**:
  - 은신 게이지: 값에 따라 채워지는 애니메이션 (부드럽게)
  - 미니맵 점: 적 위치가 업데이트될 때 부드럽게 이동 (선택적)
  - 세계 아이콘: 빌보드가 카메라를 향하여 부드럽게 회전 (옵션)
  - 상호작용 프롬프트: 약간의 펄스 애니메이션 (scale 진동)
  - 경보 플래시: ColorRect의 알파 값을 빠르게 올렸다 내림
  - 미션 텍스트: 페이드 인/아웃 시 알파 애니메이션
- **소리**:
  - 상호작용 시 클릭 소리 (짧은)
  - 경보 플래시 시 짧은 비프음
  - 미션 텍스트 변경 시 부드러운 챙 소리
  - 멈춤 메뉴 이동 시 클릭 소리, 선택 시 확정 소리
- **화면 반응**:
  - 위에서 설명한 경보 플래시, 미션 텍스트 페이드, 은신 게이지 색 변화
  - 은신 게이지 값이 높을 때 화면 가장자리에 약간의 vignette 효과 (선택적)
- **에셋 요청**:
  - 은신 게이지 배경 및 채우기 이미지 (또는 Shader로 그라데이션)
  - 미니맵 배경 이미지 (간단한 지형 윤곽) 또는 동적으로 그릴 수 있음
  - 세계 아이콘: 문서함, 탈출 지점, 적 의심/경보/탐지 아이콘 (각 상태별)
  - 상호작용 프롬프트 아이콘: 키보드 키 이미지 (E) 또는 게임패드 버튼
  - 경보 플래시용 이미지 또는 단순히 색상
  - 미션 텍스트용 폰트 (기본 Godot 폰트도 무방)
  - 멈춤 메뉴 배경 패널 및 버튼 이미지 (간단한 색상 사각형도 가능)
  - 사운드 효과: 클릭, 비프음, 챙 소리
