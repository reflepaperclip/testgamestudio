# Modern Military Stealth - UI/UX 기획서

## 1. HUD 디자인

### 1.1 은신도 게이지
- 유형: Circular/radial progress bar
- 크기: 80×80px 최소 (해상도에 따라 스케일링)
- 배경: 투명 또는 미묘한 원형 outline
- fill 색상:
  - 0-30%: `#4CAF50` (green)
  - 31-70%: `#FFC107` (amber/yellow)
  - 71-100%: `#F44336` (red)
- 테두리: 2px, `#666666`
- 표시: 중앙에 퍼센트 텍스트 (예: "73%")
- 애니메이션: 값 변경 시 0.2s 동안 부드러운 전환

### 1.2 미니맵
- 유형: Square texture rect with optional overlay nodes
- 크기: 200×200px (해상도 프리셋당 구성 가능)
- 위치: 우측 상단 모서리
- 내용:
  - 레벨 레이아웃 (간단한 개요)
  - 플레이어 위치 마커 (파란 원)
  - 적 시야 콘 (적색/주황 삼각형)
  - 목표 마커 (녹색 별)
  - 상호작용 프롬프트 마커 (느낌표!)
- 토글: 설정에서 활성화/비활성화 가능

### 1.3 목표 표시
- 유형: 중앙 상단 텍스트 레이블
- 크기: 동적, 최대 30 문자
- 색상: `#F5F5F5`
- 배경: 반투명 검은색 바 (`rgba(0,0,0,0.6)`)으로 대비 보장
- 내용: "목표: 정보 획득" / "목표: 탈출지점 도달" / "탈출 성공!" / "탐지됨! 실패..."
- 애니메이션: 상태 변경 시 0.3s 동안 페이드 인/아웃

### 1.4 상호작용 프롬프트
- 유형: 중앙 하단 텍스트 레이블
- 크기: 동적, 최대 25 문자
- 색상: `#F5F5F5`
- 배경: 대비용 반투명 바
- 내용: "{키}로 상호작용" (예: "E키로 상호작용" 또는 "패드 A버튼으로 상호작용")
- 가시성: 상호작용 가능한 객체 근처에 있을 때만 표시
- 애니메이션: 인터랙티브 객체 주위의 펄스 애니메이션 (1.0s 사이클)

### 1.5 경고 표시 (AlertFlash)
- 유형: 전체 화면 ColorRect 오버레이
- 기본 상태: 완전 투명 (`Color(1, 0, 0, 0)`)
- 탐지 시: `Color(1, 0, 0, 0.3)`와 펄스 애니메이션
- 지속 시간: 2-3초 후 페이드 아웃
- 목적: 플레이어 탐지 위험 증가 시 시각적 큐

### 1.6 알림 로그
- 유형: 왼쪽 하단 스크롤 가능한 텍스트 영역
- 최대 표시 줄: 3줄 visible
- 자동 제거: 메시지는 5초 후 페이드 (구성 가능 3-10초)
- 색상: `#F5F5F5` 텍스트 on `rgba(0,0,0,0.6)` 배경
- 내용 유형:
  - "목표 완료!"
  - "적 발견됨!"
  - "정보 획득!"
  - 커스텀 이벤트 메시지

### 1.7 조작 도움말
- 유형: 오른쪽 하단 패널 또는 전체 화면 오버레이
- 활성화: F1 키 또는 설정 토글, 또는 튜토리얼 컨텍스트
- 내용:
  - 조작 방식 표시
  - 시스템 힌트 (첫 실행 시만)
  - 접근성 옵션 미리보기
- 해제: Esc, 10초 타임아웃, 또는 수동 닫기 버튼

## 2. 메뉴 디자인

### 2.1 메인 메뉴
- 옵션: 신규 게임 시작, 계속하기, 설정, 종료
- 네비게이션: 키보드 위/아래, 마우스 스크롤, 컨트롤러 위/아래
- 포커스: 첫 번째 항목에 자동 포커스 이동

### 2.2 일시정지 메뉴
- 표시 조건: 게임 일시정지 상태 (모든 게임 프로세스 정지)
- 옵션: 계속하기, 미션 재시작, 옵션, 메인 메뉴로 복귀
- 네비게이션: 키보드 위/아래, 마우스 스크롤, 컨트롤러 위/아래
- 포커스: 첫 번째 항목 (`계속하기`)에 자동 포커스 이동

### 2.3 설정 메뉴 (일시정지 메뉴의 하위 화면)
- 그래픽 설정:
  - 해상도 드롭다운 (16:9, 16:10, 21:9)
  - 화질 품질: 낮음 / 보통 / 높음 / 울트라
  - VSync: 켜기 / 끄기
  - 플래시 효과: 켜기 / 끄기 (움직임 민감자용)
- 사운드 설정:
  - 마스터 볼륨 (0-100%)
  - 효과음 볼륨 (0-100%)
  - 음악 볼륨 (0-100%)
  - 서라운드 사운드: 켜기 / 끄기
- 컨트롤 설정:
  - 전체 키 리매핑 가능
  - 기본 값 재설정 버튼
  - 현재 바인딩 표시
- 접근성 설정:
  - 색약 모드: 켜기 / 끄기
  - 고대비 모드: 켜기 / 끄기
  - 애니메이션 감소: 켜기 / 끄기
  - 텍스트 크기: 슬라이더 (14pt - 24pt)
  - 자막 옵션: 모든 효과음 텍스트 변환

## 3. 아이콘 및 시각적 언어

### 3.1 아이콘 스타일
- 선 두께: 일관된 2px stroke
- 모서리 처리: 약간 둥근 모서리 (반경 2px)
- 채움: 아이콘에 따라 채움 또는 outline 스타일
- 색상 적용: UI 디자인 시스템의 색상 팔레트 따르기

### 3.2 주요 아이콘 목록
- 메인 메뉴: 세 줄 햄버거 아이콘
- 계속하기: 재생 삼각형
- 미션 재시작: 원형 화살표
- 옵션: 기어 아이콘
- 메인 메뉴 복귀: 집 아이콘
- 닫기: X 표시
- 설정: 슬라이더 조절 아이콘
- 리매핑: 키보드 또는 컨트롤러 아이콘
- 그래픽: 모니터 아이콘
- 사운드: 스피커 아이콘
- 컨트롤: 게임패드 아이콘
- 접근성: universal access 아이콘

### 3.3 시각적 언어 원칙
- 일관성: 모든 UI 요소에서 동일한 스타일 적용
- 명확성: 아이콘의 의미가 즉시 인식 가능하도록 설계
- 피드백: 상호작용 시 시각적 및 청각적 피드백 제공
- 접근성: 색상 외에도 모양과 위치로 정보 전달

## 4. 접근성 고려 사항

### 4.1 색약 지원
- 은신도 게이지: 색상Additionally 두께와 무늬로 구분 (예: 0-30%는 얇은 실선, 31-70%는 중간 점선, 71-100%는 두꺼운 대시)
- 경고 표시: 색상조차도 패턴으로 구분 (예: 점선 vs 실선 펄스)
- 중요한 정보: 색상만이 아닌 다른 시각적 단서로 보강

### 4.2 텍스트 크기 스케일링
- 기본 크기: 1920×1080에서 14pt
- 해상도에 따라 비례하여 스케일링
- 설정에서 텍스트 크기 재정의 가능 (14pt~24pt 범위)

### 4.3 입력 리매핑
- 모든 UI 액션은 InputMap을 통해 완전 리매핑 가능
- 하드코딩된 키 가정 없음
- 리매핑 설정은 설정 메뉴의 컨트롤 섹션에서 관리

### 4.4 스크린 리더 지원
- UI 요소에는 AccessibleName 속성을 통해 접근 가능한 이름 제공
- 스크린 리더가 요소를 올바르게 설명하고 상호작용 가능

### 4.5 운동 감소 옵션
- 설정에서 펄스 애니메이션과 플래시 효과 비활성화 가능
- 핵심 기능에는 영향 없으나 보조 시각 효과 감소

### 4.6 고대비 모드
- 설정에서 고대비 모드 활성화 시:
  - 텍스트: `[FFFFFF]` on `[000000]` 배경
  - UI 요소: 고대비 색상 팔레트 적용
  - 중요한 정보의 가시성 극대화

## 5. Godot 구현 참고 사항

### 5.1 테마 및 씬
- 테마: `res://ui/theme/default_hud.tres`
- 메인 HUD 씬: `res://ui/main_hud/main_hud.tscn`

### 5.2 주요 시그널
- `stealth_updated(exposure: float)`: 은신도 레벨 변경 시 발출
- `audibility_updated(exposure: float)`: hörbarheid 레벨 변경 시 발출
- `objective_updated(new_objective: String)`: 목표 변경 시 발출
- `interaction_prompt_shown(show: Boolean, action_name: String)`: 상호작용 프롬프트 표시 시 발출
- `notification_added(message: String, duration: float)`: 알림 추가 시 발출
- `help_toggled(show: Boolean)`: 도움말 오버레이 토글 시 발출

### 5.3 UI 노드 계층 구조 (main_hud.tscn 기준)
```
CanvasLayer (MainHUD)
└── AnchorContainer (전체 화면)
    ├── StealthGauge (TextureProgressBar) - 좌측 하단
    ├── Minimap (TextureRect) - 우측 상단
    ├── ObjectiveLabel (Label) - 상단 중앙
    ├── InteractionPrompt (Label) - 하단 중앙
    └── AlertFlash (ColorRect) - 다른 요소들 뒤에 있는 전체 화면
```

## 6. 반응형 디자인

### 6.1 브레이크포인트
- Wide 16:9: 1920×1080 (기본 레이아웃)
- Tall 16:10: 1920×1200 (수직 간격 조정, 미니맵 높이 증가)
- UltraWide 21:9: 2560×1080 (수평 공간 확장, HUD 요소 넓게 분산)
- Vertical 9:16: 1080×1920 (모바일) (컴팩트 레이아웃, 축소 가능한 섹션, 우선순위 재정렬)

### 6.2 반응형 원칙
- 핵심 기능은 절대 손상되지 않음
- 보조 요소는 축소 또는 재정렬 가능
- 중요한 정보 (은신도 게이지, 목표 표시, 미니맵)는 모든 프리셋에서 _visible 필수
