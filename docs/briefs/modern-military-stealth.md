# Modern Military Stealth

## 개요
- 플랫폼: PC(Windows)
- 장르: 탑다운 잠입슈터
- 소재/배경: 현대 밀리터리 택티컬
- 한 줄 요약: 은신과 전략을 통해 적 기지를 잠입하여 정보를 훔치는 긴장감

## 범위
- 플레이 시간: 15분 버티컬스라이스
- 맵 수: 1개
- 플레이 모드: 싱글플레이

## 제약 조건
- 에셋: Blender로 모델·리깅·애니메이션 직접 제작, 텍스처는 ambientCG 같은 CC0 사이트에서 조달, 기존 게임 IP 복제 금지
- 기술: Godot 4.7 사용
- 기타: 과도한 폭력 가능 (구체적인 폭력 수위 정의 필요)

## 성공 기준
- 특정 메커니즘(은신 시스템, 적 AI 등)이 잘 작동하는지 확인
- 플레이테스트에서 핵심 루프(은신 → 정보 획득 → 탈출)가 원활하게 실행되는지 검증
- 적 AI가 플레이어의 행동을 적절히 감지하고 반응하는지 확인

## 산출물
- 에셋이 포함된 프로토타입 (버티컬스라이스 빌드)
- 게임 설계 문서 (GDD)
- 시스템 기획서 (은신 시스템, 적 AI, 레벨 디자인)
- 레벨 기획서 (1개 맵 디자인)
- UI/UX 기획서
- ASSETS.md (에셋 목록 및 출처 기록)
- 테스트 결과 및 피드백 문서

## 승인 게이트
1. **브리프 게이트**: 사용자 승인 (현재 단계)
2. **기획 게이트**: GDD, 시스템·레벨·UI 기획서 승인 후 진행
3. **프로토타입 게이트**: 핵심 루프 실행 빌드 시人 플레이 점검 후 진행
4. **에셋 제작 게이트**: 모델·텍스처 및 ASSETS.md 품질 점검 후 진행
5. **통합·테스트 게이트**: 빌드 및 테스트 결과 사용자 확인 후 완료
