## 2. 후보 3개

### 후보 1: 현대 군사 스텔스 (현재 기획)
- **한 줄 요약**: 현대 전투원을 배경으로 한 은신도 기반 스텔스 액션, 적의 시야와 청각을 피해 목표를 달성하는 긴장감 있는 게임플레이
- **장르**: 스텔스 액션
- **소재**: 현대 군사, 특수부대 작전
- **플레이 루프**: 은신하여 이동 → 탐지 위험 평가 → 행동 선택 (은신 이동/침묵 제거/우회) → 은신도 관리 → 목표 달성
- **차별점**: 
  - 실시간 은신도 게이지로 노출 수준 직관적 표시
  - 절차적 적 배치로 기억에 의존하지 않는 플레이 요구
  - 현대 군비의 현실적 제약과 가능성을 기반으로 한 장비 시스템
- **실현 가능성 점수표** (1-5점, 높을수록 좋음)
  | 항목 | 점수 | 근거 |
  |---|---|---|
  | 에셋 부담 | 3 | 인간 모델 및 군사 장비 모델링 필요, 하지만 블렌더로 기본 제작 가능 |
  | 시스템 복잡도 | 3 | AI 탐지 및 은신도 시스템 복잡하나 Godot로 구현 가능 |
  | 검증 용이성 | 4 | 헤드리스 테스트로 은신도 값 및 탐지 로직 검증 가능 |
  | 차별성 | 4 | 기존 스텔스 게임과 달리 실시간 수치 기반 은신도 시스템 |
  | 플레이타임 | 5 | 10-15분 버티컬 슬라이스로 핵심 루프 demonstrable |
- **위험**: 
  - AI 탐지 로직의 복잡성으로 인한 버그 가능성
  - 은신도 게이지의 직관성 부족 시 플레이어 혼란

### 후보 2: 절차적 생성 지하 탐험
- **한 줄 요약**: 매번 변화하는 지하 시설에서 자원을 채집하고 생물체를 피해 탈출하는 서바이벌 탐험 게임
- **장르**: 서바이벌 탐험
- **소재**: 과학 시설, 외계생물
- **플레이 루프**: 시설 탐색 → 자원 채집 → 장비 제작 → 생물체 회피 또는 combat → 탈출구 찾기
- **차별점**: 
  -毎層이 다른 구조와 위협을 가진 절차적 생성 레벨
  - 자원 채집과 장비 제작이 탐험과 직접 연결된 루프
  - 소리 기반 탐지 시스템 (플레이어의 행동이 소음을 발생시켜 적을 유인)
- **실현 가능성 점수표**
  | 항목 | 점수 | 근거 |
  |---|---|---|
  | 에셋 부담 | 4 | 기본적인 시설 모듈과 생물체 모델 필요, 변형이 적음 |
  | 시스템 복잡도 | 3 | 절차적 생성 알고리즘과 자원 시스템 필요 |
  | 검증 용이성 | 3 | 절차적 생성의 randomness로 인해 재현성 테스트 어려움 |
  | 차별성 | 4 | 탐험과 서바이벌을 결합한 루프와 소리 기반 탐지 |
  | 플레이타임 | 4 | 10-15분 내에 한 층 탐험 및 탈출 가능 |
- **위험**: 
  - 절차적 생성이 때로는 불가능하거나 지루한 레벨을 생성할 수 있음
  - 자원 균형 조정의 어려움

### 후보 3: 협동 폭탄 해체 시뮬레이션
- **한 줄 요약**: 플레이어가 폭탄 해체 전문가가 되어 제한 시간 내에 모듈을 해체하며 협력하고 소통하는 파티 게임
- **장르**: 협동 파티 게임
- **소재**: 폭탄 해체, 긴장감 있는 상황
- **플레이 루프**: 폭탄 제시 → 역할 할담 (해체 전문가 vs 매뉴얼 보유자) → 소통을 통한 모듈 해체 → 시간 내 완료 또는 실패
- **차별점**: 
  - asymmetric gameplay: 한 명은 폭탄을 보고, 다른 이들은 매뉴얼을 보며 소통해야 함
  - 모듈 기반 폭탄 구조로 무한한 변형 가능
  - 소리 채팅을 통한 실시간 소통이 필수
- **실현 가능성 점수표**
  | 항목 | 점수 | 근거 |
  |---|---|---|
  | 에셋 부담 | 5 | 간단한 폭탄 모듈 모델과 UI 중심 |
  | 시스템 복잡도 | 2 | 네트워크 동기화 필요하지만 간단한 상태 동기화 |
  | 검증 용이성 | 3 | 네트워크 지연 등으로 인한 검증 복잡성 |
  | 차별성 | 5 | clairement asymmetric 협력 구조 |
  | 플레이타임 | 5 | 한 라운드가 2-3분으로 버티컬 슬라이스 용이 |
- **위험**: 
  - 네트워크 동기화 필수 (싱글 플레이 가능 모드 필요 고려)
  - 소통에 의존하는 게임플레이로 인해 접근성 문제 가능

## 3. 추천 후보 및 이유

**추천 후보**: 후보 1: 현대 군사 스텔스

**선유 이유**:
1. **팀 역량 적합**: Godot 4.7과 Blender 5.2.2로 인간 모델 및 군사 장비 제작이 가능하며, 은신도 및 탐지 시스템은 Godot의 노드 시스템으로 구현 가능.
2. **차별성 명확**: 실시간 수치 기반 은신도 시스템은 기존 스텔스 게임과 뚜렷한 차이를 제공하며, 긴장감 조절이라는 필러를 직접적으로 구현 가능.
3. **스코프 관리**: 버티컬 슬라이스로 10-15분 내에 핵심 루프(은신도 관리, 탐지 회피, 목표 달성)를 시연할 수 있음.
4. **트렌드 적합**: 스텔스 장르의 인기 상승 (+3%)과 서사적 요소가 아닌 순수 게임플레이에 집중할 수 있음.
5. **확장 가능성**: 핵심 시스템이 완성되면 다양한 미션 유형, 장비 추가, 스토리 모드 등으로 확장 가능.

**사용자에게 확인할 질문**:
1. 현대 군사 스텔스 게임의 핵심 목표는 무엇이라고 생각하는가? (예: 정보 획득, 목표 제거, 탈출 등)
2. 은신도 시스템 외에도 긴장감을 높일 수 있는 시스템으로 무엇을 고려하고 있는가?
3. 버티컬 슬라이스에서 반드시 보여야 하는 요소는 무엇이라고 생각하는가? (예: 특정 미션 시나리오, 장비 시스템 등)
