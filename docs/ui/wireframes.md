# Wireframes

## Main HUD Wireframe (1920×1080, 16:9)

```
┌──────────────────────────────────────────────────────┐
│  ┌───────────────────────┐  미니맵 (200×200)      │
│  │                       │  ┌────────────────────┐     │
│  │   목표: 정보 획득      │  │  [레아웃 개요]       │
│  │   (상단 중앙)          │  │  - 플레이어: 파란원 │
│  │                       │  │  - 적 시야: 빨간삼 │
│  │                       │  │  - 목표: 초록별     │
│  └───────────────────────┘  └────────────────────┘     │
│                                                        │
│  ┌───────────────────────┐  상호작용 프롬프트          │
│  │   E키로 상호작용       │  └────────────────────┬──┘
│  │   (하단 중앙)          │                      ↓
│  └───────────────────────┘                      "E키로 상호작용"
│                                                        │
│  ┌────────────────────────────────────────────────┐   │
│  │  ┌─────────────┐  은신도 게이지 (80×80)           │   │
│  │  │ 00%        │  ┌─────────────┐                          │   │
│  │  │ (원형)     │  │  깔라        │                          │   │
│  │  └─────────────┘  └─────────────┘                          │   │
│  └────────────────────────────────────────────────┘   │
│                                                        │
│  ┌───────────────────────┐  알림 로그 (좌측 하단)       │
│  │                       │  ┌────────────────────┐       │
│  │                       │  │ "적 발견됨!"        │       │
│  │                       │  │ (최신 3줄까지 표시) │       │
│  └───────────────────────┘                                │
└──────────────────────────────────────────────────────┘
```

> **주석**: 절대 픽셀 좌표를 사용하지 않음. 모든 위치는 앵커와 컨테이너 규칙으로 정의함. 
> **앵커 요약**: 
> - 은신도 게이지: `(0, 1, 0, 1)` 좌측 하단, 마진 `(20, -60, 0, 20)` from bottom-left
> - 미니맵: `(1, 0, 1, 0)` 우측 상단, 마진 `(-220, 20, 20, 0)` from top-right  
> - 목표 라벨: `(0.5, 0, 0.5, 0)` 중앙 상단
> - 상호작용 프롬프트: `(0.5, 1, 0.5, 1)` 중앙 하단, 마진 `(0, -40, 0, 20)` from bottom
> - 알림 로그: `(0, 1, 0, 1)` 좌측 하단, 기본 여백 없음

## Pause Menu Wireframe

```
┌────────────────────────────────────────────┐
│  [PAUSE MENU]                              │
│  ┌───────────────────────┐                 │
│  │ continue               │   [이미지/아이콘]   │
│  │                        │                   │
│  │ restart mission        │                   │
│  │                        │                   │
│  │ options                │   [사운드 아이콘]   │
│  │                        │                   │
│  │ main menu              │   [메인 메뉴 아이콘] │
│  └───────────────────────┘                 │
│                                              │
│  [닫기(X)]  [설정(S)]  [리마핑(R)]           │
└────────────────────────────────────────────┘
```

> **상태**: 일시정지 상태에서 표시. 모든 게임 프로세스 일시화.
> **네비게이션**: 키보드 위/down, 마우스 스크롤, 또는 컨트롤러 업/다운.
> **포커스**: 첫 번째 항목 (`continue`)에 자동 포커스 이동.

## Settings Menu Wireframe (sub-screen of Pause Menu)

```
┌────────────────────────────────────────────┐
│  [SETTINGS]                                │
│  ┌───────────────────────┐                 │
│  │ 그래픽                 │   [그래픽 아이콘]   │
│  │                        │                   │
│  │ 사운드                 │   [사운드 아이콘]   │
│  │                        │                   │
│  │ 컨트롤                 │   [컨트롤 아이콘]   │
│  │                        │                   │
│  │ 접근성                 │   [접근성 아이콘]   │
│  └───────────────────────┘                 │
│                                              │
│  [닫기(X)]                                                 │
└────────────────────────────────────────────┘
```

> **그래픽 설정 항목**:
> - 해상도 드롭다운 (16:9, 16:10, 21:9)
> - 화질 품질: 낮음 / 보통 / 높음 / 울트라
> - VSync: 켜기 / 끄기
> - 플래시 효과: 켜기 / 끄기 (운동병용자용)

> **사운드 설정 항목**:
> - 마스터 볼륨 (0-100%)
> - 효과음 볼륨 (0-100%)
> - 음악 볼륨 (0-100%)
> - 서라운드 사운드: 켜기 / 끄기

> **컨트롤 설정 항목**:
> - 전체 키 리매핑 가능
> - 기본 값 재설정 버튼
> - 현재 바인딩 표시

> **접근성 설정 항목**:
> - 색약 모드: 켜기 / 끄기
> - 고대비 모드: 켜기 / 끄기
> - 애니메이션 감소: 켜기 / 끄기
> - 텍스트 크기: 슬라이더 (14pt - 24pt)
> - 자막 옵션: 모든 효과음 텍스트 변환

## Tutorial/Onboarding Flow Wireframe

```
Screen 1: Introduction
────────────────────────────────────────────
[게임 제목 로고]
[any key to continue 또는 스키ップ]

Screen 2: Movement
────────────────────────────────────────────
[WASD]: 이동
[Shift]: 달리기
[Space]: 점프
[E]: 상호작용

[화살표]: 이동 방향 표시 →

Screen 3: Stealth
────────────────────────────────────────────
[은신도 게이지]: 0-100% 표시
[적 시야]: 원뿔 모양 표시 (현재 방향)
[커버]: 벽/가림막 뒤에 서면 탐지 감소

[시야 각도 표시]: ←↑→ 표시

Screen 4: Info Collection
────────────────────────────────────────────
[접근]: 정보 객체에 다가가기
[프롬프트]: "E키로 상호작용"
[진행도 바]: 채워지는 애니메이션
[성공]: "정보 획득!" + 효과음

[완료]: 다음 단계로 진행 화살표

Screen 5: Escape
────────────────────────────────────────────
[탈출로]: 표시된 경로 따라 이동
[적]: 증가된 속도로 추적
[안전 지점]: 원형 영역 도착 시 승리
[축하]: "탈출 성공!" + 팬파이어 효과음
```

## Game Over / Failed Wireframe

```
┌────────────────────────────────────────────┐
│  ⚠️  탐지됨! 실패...                        │
│  ┌───────────────────────┐                 │
│  │ 다시 시도               │   (레벨 다시 시작) │
│  │                       │                   │
│  │ 메인 메뉴로             │   (타이틀 화면 복귀)│
│  └───────────────────────┘                 │
│                                              │
│  [닫기]  [재시도]  [메인 메뉴]              │
└────────────────────────────────────────────┘
```

> **플레이어 피드백**: 
> - 화면 가장자리 빨간색 플래시 (AlertFlash)
> - 오디오: 급격한 경보음 + 효과음
> - 화면 플래시: 흰색 플래시 효과
> - 지속 시간: 2초 후 자동 복구 옵션 가능

## Success / Complete Wireframe

```
┌────────────────────────────────────────────┐
│  ✓  탈출 성공!                              │
│  ┌───────────────────────┐                 │
│  │ 다음 미션으로           │   (새 미션 시작) │
│  │                       │                   │
│  │ 메인 메뉴로             │   (타이틀 화면 복귀)│
│  └───────────────────────┘                 │
│                                              │
│  [닫기]  [다음 미션]  [메인 메뉴]           │
└────────────────────────────────────────────┘
```

> **플레이어 피드백**: 
> - 화면 확대 효과 + 축하 애니메이션
> - 오디오: 승리 팬파이어 효과음
> - 업적 잠금 해제 여부 표시
> - 기록: 미션 완료 시간, 통계 표시
