# Modern Military Stealth - Game Design Document

## 개요
- 플랫폼: PC(Windows)
- 장르: 탑다운 잠입슈터
- 소재/배경: 현대 밀리터리 택티컬
- 한 줄 요약: 은신과 전략을 통해 적 기지를 잠입하여 정보를 훔치는 긴장감

## 범위
- 플레이 시간: 15분 버티컬스라이스
- 맵 수: 1개
- 플레이 모드: 싱글플레이

## 핵심 게임 플레이 루프
1. 은신: 적의 시야와 소리를 피하며 이동
2. 정보 획득: 목표 객체와 상호작용하여 정보를 획득
3. 탈출: 정보 획득 후 증가된 추적을 피해 탈출 지점까지 도달

## 게임 시스템
### 은신 시스템
- 적의 시야 감지 (원뿔형, 장애물 고려)
- 적의 청각 감지 (소리 기반, 거리 감쇠)
- 의심 및 경보 상태 (탐지 → 의심 → 경보 → 전투)
- 은신 성공 조건: 적의 감지 범위 밖에서 일정 시간 머무름

### 적 AI 시스템
- 상태 기반 행동: 순찰, 탐색, 추적, 경보
- 시야 기반 탐지: 앞쪽 원뿔 영역 내 플레이어 시각적 탐지
- 청력 기반 탐지: 주위 소리 청취 및 위치 추정
- 정보 공유 시스템: 탐지된 정보를 일정 반경 내에서 공유
- 기억 시스템: 일정 시간 동안 플레이어의 마지막 알려진 위치 기억

### 정보 시스템
- 상태 기반 객체: 미활성화 → 상호작용 중 → 활성화(정보 획득)
- 상호작용 트리거: 거리 및 각도 조건 확인 후 상호작용 시작 가능
- 정보 획득 프로세스: 상호작용 후 일정 시간 동안 정보 획득 진행
- 획득 효과: 정보 획득 시 적 행동 변경, 환경 변화, 스토리 진행

### 탈출 시스템
- 목표 전환 트리거: 정보 획득 시 탈출 목표로 자동 전환
- 추적 시스템 활성화: 정보 획득 후 적들의 행동이 순찰에서 추적으로 변화
- 탈출 조건 판단: 플레이어가 탈출 지점에 도달했을 때 미션 성공 처리
- 난이도 동적 조정: 탈출 중 상황 난이도를 정보 획득 시점과 시간 등에 따라 조정

### UI/UX 시스템
- 은신도 게이지 (좌측 중앙)
- 미니맵 (우측 상단) - 적 시야 표시
- 목표 표시 (상단 중앙)
- 경고 표시 (화면 가장자리 점멸)
- 상호작용 프롬프트 (하단 중앙)
- 알림 로그 (좌측 하단)
- 조작 도움말 (우측 하단)

## 레벨 디자인
- 첫 미션: 인질 정보 acquisition
- 구역 구성: 진입점, 순찰로, 은신 연습 구역, 첫 정보 포인트, 경비 초소, 메인 건출, 정보 객체, 탈출로, 추적 구역, 탈출점
- 핵심 경로: A → B → C → D → E → F → G → H → I → J
- 선택 경로: 지름길 및 루트 존재
- 페이싱: 긴장/휴식 곡선 정의
- 배치: 적/오브젝트 배치 및 근거
- Godot 구현 연결: 씬 파일 경로, 루트 노드, 구획 단위 서브씬, 충돌 레이어, 내비게이션 영역, 스폰 포인트, 로드/스트리밍 단위
- 표현 요소: 조명 톤, 환경음, 시그니처 랜드마크, 에셋 요청 목록
- 플레이 테스트 항목: 길 잃는 지점 예측, 난이도 스파이크 예측, 막힘 방지 점검

## 아트 및 에셋
- 모델: Blender로 직접 제작 (건물 외벽, 내부 설비, 순찰로 지형, 은신 전용 암그림자, 적 보병 모델, 정보 객체 모델, 조명 효과, 탈출 지점 모델)
- 텍스처: ambientCG 같은 CC0 사이트에서 조달
- 애니메이션: 순찰, 탐색, 추적 애니메이션 (각 방향별)
- 효과음: 발소리, 발견 소리, 총소리, 상호작용 소리, 세계 변화 소리, 승리/실패 효과음, 추적 중 효과음
- UI 요소: 은신도 게이지, 미니맵 아이콘, 상호작용 프롬프트 아이콘, 알림 로그, 조작 도움말

## 기술 스택
- 엔진: Godot 4.7
- 언어: GDScript
- 플랫폼별 설정: PC(Windows) 최적화
- 저장소 구조: 
  - 씬: `res://scenes/`
  - 스크립트: `res://scripts/`
  - 에셋: `res://assets/`
  - 오디오: `res://audio/`

## 개발 로드맵 및 마일스톤
1. 브리프 게이트: 사용자 승인 (완료)
2. 기획 게이트: GDD, 시스템·레벨·UI 기획서 승인 후 진행
3. 프로토타입 게이트: 핵심 루프 실행 빌드 시 인간 플레이 점검 후 진행
4. 에셋 제작 게이트: 모델·텍스처 및 ASSETS.md 품질 점검 후 진행
5. 통합·테스트 게이트: 빌드 및 테스트 결과 사용자 확인 후 완료

## 성공 기준
- 특정 메커니즘(은신 시스템, 적 AI 등)이 잘 작동하는지 확인
- 플레이테스트에서 핵심 루프(은신 → 정보 획득 → 탈출)가 원활하게 실행되는지 검증
- 적 AI가 플레이어의 행동을 적절히 감지하고 반응하는지 확인
